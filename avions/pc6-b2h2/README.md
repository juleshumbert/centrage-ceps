# Pilatus PC-6/B2-H2 Turbo Porter

`envelope.json` : donnees propres au B2-H2 (MTOW = MLW 2200 kg, enveloppe 1450 kg : 3.209 m,
2200 kg : 3.475 a 3.646 m, soit 11 / 25 / 34 % MAC), extraites du meme travail de recherche
que le B2-H4.

Les notes sourcees (TCDS OFAC F 56-10, AFM 1820, brochures, directive technique FFP n° 33),
les PDF et les figures sont dans `../pc6-b2h4/` : le fuselage, le datum (3 m devant le bord
d'attaque), les rangees de sieges et les portes sont communs aux deux variantes ; seuls
l'envergure (15.2 m contre 15.87 m), la motorisation (PT6A-27 contre PT6A-34), les masses et
l'enveloppe different. Aucun AFM B2-H2 n'a ete trouve en PDF public.
